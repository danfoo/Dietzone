❌ Problème : Service Worker 404
   Solution : Vérifier que firebase-messaging-sw.js est bien à la RACINE
             (même niveau que index.php, pas dans un sous-dossier)

❌ Problème : Page diagnostic dit "✗ MANQUANT"
   Solution : Vider le cache du navigateur (Ctrl+Shift+R)
             Vérifier les permissions du fichier (644 recommandé)

❌ Problème : Erreur 500 sur test_push
   Solution : Vérifier que le fichier test_push.php existe bien dans
             modules/dietetic/views/admin/notifications/

❌ Problème : "Permission non accordée"
   Solution : C'est normal si c'est la première fois
             Cliquer à nouveau sur le bouton
             Autoriser dans le popup du navigateur
