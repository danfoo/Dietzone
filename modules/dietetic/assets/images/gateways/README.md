# Logos des Passerelles de Paiement

Ce dossier contient les logos des différentes passerelles de paiement utilisées dans le module Dietetic.

## Instructions

Pour ajouter le logo Wave :
1. Téléchargez le logo Wave (format PNG recommandé)
2. Renommez-le en `wave-logo.png`
3. Placez-le dans ce dossier (`modules/dietetic/assets/images/gateways/`)
4. Le logo s'affichera automatiquement sur la page de paiement

## Logos supportés

- **wave-logo.png** - Logo de Wave (format recommandé : 200x200px, fond transparent)
- **paypal-logo.png** - Logo PayPal (optionnel, l'icône FontAwesome est utilisée par défaut)
- **orange-money-logo.png** - Logo Orange Money (optionnel)

## Dimensions recommandées

- Largeur : 200px
- Hauteur : 200px
- Format : PNG avec fond transparent
- Taille maximale : 100KB

## Fallback

Si un logo n'est pas trouvé, une icône ou un texte stylisé sera affiché à la place.
